## Summary

QuarkOS Capes is a Fabric, Forge, and NeoForge client mod for Minecraft 1.20.1, 1.21.1, 1.21.4, 1.21.8, and 1.21.11. NeoForge jars start at 1.21.1. Pick a local cape, play a frame strip, sim cloth, or wear a cube cloak. Read public cape APIs when you turn a provider on. Share a cape through your own gallery service. Animated capes are free. The per-file game versions and loaders are in `docs/RELEASE.md`.

## Required

- Minecraft 1.20.1, 1.21.1, 1.21.4, 1.21.8, or 1.21.11, matching the jar
- Fabric Loader 0.16.0 or newer
- Fabric API
- Java 21
- Cloth Config (already inside the jar; GNU LGPLv3, author shedaniel)

## Optional

- Mod Menu, if you want the mods list to open the same screen. The O key works without it.

## Embedded

- OkHttp 3.14.9 and Okio 1.17.5, Apache-2.0
- Cloth Config, GNU LGPLv3, not relicensed

Gson is Minecraft's own copy. Architectury is not required. GeckoLib is not required.
