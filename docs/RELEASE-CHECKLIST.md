## Featured API check on Windows

Build the server jar in the capes-site checkout and start its `scripts/featured-api.ps1`. Use a development run directory for the mod. From the mod root in a second PowerShell window, load the local test secret and run the UI harness. Set `$site` to the location of your capes-site checkout.

```powershell
$site = 'D:\dev\capes-site'
$env:CAPES_DEV_AUTH = 'true'
$env:CAPES_DEV_AUTH_SECRET = [IO.File]::ReadAllText((Join-Path $site 'server\data\featured-local\dev-auth.secret')).Trim()
.\gradlew.bat :1.21.11:runClient -Ponly=ui -PallowLocalService=true -PserverUrl=http://127.0.0.1:8787 "-Pshots=$PWD\build\featured-ui"
```

Repeat with `:26.3:runClient` and a different output directory. The first response from Browse should log `CAPE_API featured=11 animated=3 source=http://127.0.0.1:8787` for the shipped manifest. Check that `ui-result.txt` reports `fail=0`. Inspect `ui-featured-list.png`, `ui-featured-preview.png`, and `ui-featured-world-back.png`. The preview result includes the frame index drawn at capture.

Stop the local server and repeat with a fresh output directory. The featured stages should report a service-unavailable skip, and the local offline and Advanced URL 404 checks should pass.
